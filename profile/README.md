# Odenwilusenz

Willkommen beim GitHub-Auftritt von **Odenwilusenz**.

Hier sammeln wir Projekte, Experimente, Hardware, Software und Dokumentation aus dem Hackerspace-Umfeld. Einige Projekte werden direkt in dieser Organisation gepflegt, andere von einzelnen Mitgliedern in ihren eigenen GitHub-Accounts weitergeführt.
